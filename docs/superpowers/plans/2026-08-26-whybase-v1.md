# Whybase v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One Go binary (`whybase`) that authors, AI-drafts, links, integrity-checks, and MCP-serves MADR architecture decision records in any repo.

**Architecture:** Pure `internal/adr` (markdown parse/render), `internal/store` (discovery/index/integrity/search) on top of it, `internal/draft` (gh diff → pluggable LLM provider), `internal/mcpserver` (stdio MCP over store), thin cobra CLI in `cmd/whybase`. Files are the database; no daemon.

**Tech Stack:** Go 1.24 · `spf13/cobra` · `gopkg.in/yaml.v3` · `modelcontextprotocol/go-sdk` (MCP stdio) · `gh` CLI invoked via `exec.Command` for PR data · Anthropic + OpenAI REST via `net/http` (no SDKs).

## Global Constraints

- Module path: `github.com/mkfeuhrer/whybase`; binary name `whybase`.
- Records live in `doc/adr/` by default; overridable via `.whybase.yml` key `adr_dir`.
- File naming: zero-padded 4-digit `NNNN-slug.md` (adr-tools compatible).
- Canonical writer output = YAML front-matter + MADR body sections. Parser must ALSO read legacy MADR files (no front-matter) without mutating them.
- Statuses (lowercase): `proposed`, `accepted`, `superseded`, `deprecated`.
- Front-matter keys: `number`, `title`, `status`, `date` (`YYYY-MM-DD`), `supersedes`, `superseded_by`, `tags`.
- No network calls except: `draft` command hitting LLM APIs and `gh`. All other commands work offline.
- Every task ends with `go test ./...` green and a commit.
- TDD throughout: failing test first, watch it fail, minimal impl, watch it pass.
- Spec reference: `docs/superpowers/specs/2026-08-26-whybase-v1-design.md`.

```go
package cli

import (
	"fmt"
	"os"
	"path/filepath"

	"gopkg.in/yaml.v3"
)

type Config struct {
	ADRDir string `yaml:"adr_dir"`
}

func LoadConfig(root string) (Config, error) {
	cfg := Config{ADRDir: "doc/adr"}
	b, err := os.ReadFile(filepath.Join(root, ".whybase.yml"))
	if os.IsNotExist(err) { return cfg, nil }
	if err != nil { return cfg, err }
	if err := yaml.Unmarshal(b, &cfg); err != nil { return cfg, fmt.Errorf(".whybase.yml: %w", err) }
	if cfg.ADRDir == "" { cfg.ADRDir = "doc/adr" }
	return cfg, nil
}
```

- [ ] **Step 3: Implement** — `internal/adr/record.go`: detect leading `---\n`, yaml.Unmarshal into shadow struct, map to Record, keep remainder as Body verbatim; wrap yaml errors with `fmt.Errorf("front-matter %w")` plus computed line offset (count lines before body; add to yaml.Line).

```go
package adr

import (
	"bytes"
	"errors"
	"fmt"
	"strings"

	"gopkg.in/yaml.v3"
)

type Status string

const (
	Proposed   Status = "proposed"
	Accepted   Status = "accepted"
	Superseded Status = "superseded"
	Deprecated Status = "deprecated"
)

func ValidateStatus(s string) (Status, error) {
	st := Status(s)
	switch st {
	case Proposed, Accepted, Superseded, Deprecated:
		return st, nil
	}
	return "", fmt.Errorf("invalid status %q (want proposed|accepted|superseded|deprecated)", s)
}

type Record struct {
	Number       int      `yaml:"number"`
	Title        string   `yaml:"title"`
	Status       Status   `yaml:"status"`
	Date         string   `yaml:"date"`
	Supersedes   []int    `yaml:"supersedes,omitempty"`
	SupersededBy []int    `yaml:"superseded_by,omitempty"`
	Tags         []string `yaml:"tags,omitempty"`
	Body         string   `yaml:"-"`
}

var errNoFM = errors.New("no front-matter")

func splitFrontMatter(src []byte) (meta []byte, rest []byte, err error) {
	if !bytes.HasPrefix(src, []byte("---\n")) { return nil, src, errNoFM }
	end := bytes.Index(src[4:], []byte("\n---\n"))
	if end < 0 { return nil, nil, errors.New("unterminated front-matter (missing closing ---)") }
	return src[4 : 4+end], src[4+end+5:], nil
}

func Parse(src []byte) (Record, error) {
	meta, rest, err := splitFrontMatter(src)
	var r Record
	if errors.Is(err, errNoFM) {
		r.Body = string(src)
		return r, nil // legacy parsing added in Task 3
	}
	if err != nil { return r, err }
	if uerr := yaml.Unmarshal(meta, &r); uerr != nil {
		var ye *yaml.TypeError
		line := 0
		if errors.As(uerr, &ye) && len(ye.Errors) > 0 { line = extractLine(ye.Errors[0]) }
		return r, fmt.Errorf("front-matter line %d: %w", line+1, uerr)
	}
	if r.Number <= 0 { return r, errors.New("front-matter: number must be > 0") }
	if _, serr := ValidateStatus(string(r.Status)); serr != nil {
		return r, fmt.Errorf("front-matter: %w", serr)
	}
	r.Body = string(rest)
	return r, nil
}

func extractLine(msg string) int {
	var n int
	if _, err := fmt.Sscanf(msg, "line %d:", &n); err == nil { return n - 1 }
	return 0
}

// TrimSpace helper reused by render/tests
func trimNL(s string) string { return strings.TrimLeft(s, "\n") }
```
